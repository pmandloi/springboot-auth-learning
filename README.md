# Spring Boot Authentication Learning Project

This repository is a **learning hub** for implementing different authentication and authorization approaches in Spring Boot.  
The **master branch** contains the basic project setup and acts as a central reference.

---

## 📂 Branches Overview

| Branch Name               | Description                                           | Link |
|----------------------------|-------------------------------------------------------|------|
| `master`                  | Base project setup with Maven, Spring Boot, and README | [Switch to master](https://github.com/pmandloi/springboot-auth-learning/tree/master) |
| `api-access-via-jwt-token`               | JWT (JSON Web Token) authentication implementation   | [Switch to jwt-basic](https://github.com/pmandloi/springboot-auth-learning/tree/api-access-via-jwt-token) |
| `jwt-refresh`             | JWT with Refresh Token support                        | [Switch to jwt-refresh](https://github.com/pmandloi/springboot-auth-learning/tree/jwt-refresh) |
| `oauth2-google`           | OAuth2 / Google login implementation                  | [Switch to oauth2-google](https://github.com/pmandloi/springboot-auth-learning/tree/oauth2-google) |

---

## ⚡ Master Branch Contents

The master branch includes:

- Standard Spring Boot Maven project structure.
- `.gitignore`, `.mvn/`, `pom.xml`, and `src/` folder.
- Basic README and project setup.
- No authentication implemented yet — serves as a clean base for experimenting.
